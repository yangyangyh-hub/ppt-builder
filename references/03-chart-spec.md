# 03 图表规范（数据图）

## 1. 先判能不能画

1. 这个数有权威出处吗（统计公报、年鉴、部委监测、行业协会年报、已发表论文）？**没有就不画**，改一句带数字的文字结论。
2. 出处是"年度口径"还是"快报/监测口径"？同一张图里不混两种口径。
3. 用户要的是"构成比例"还是"总量趋势"？前者只能用编制口径一致的年份，后者可以用当年快报。

降级顺序：有出处的图 → 文字结论 → 不画。**无出处的曲线比没有图更伤分。**

## 2. 出图参数（保证图内字号 = 版面字号）

```python
W_CM, H_CM = 9.83, 7.37          # 与占位框完全一致
fig = plt.figure(figsize=(W_CM/2.54, H_CM/2.54), dpi=340)
```

- figsize 与版面 1:1 ⇒ **图内 pt 就是版面 pt**，不用反复试字号。
- dpi 340 ⇒ 1318×989 px，投影与打印都够。
- 字体：`font.family=['Times New Roman','Microsoft YaHei']`，`weight=bold`，注册 `msyh.ttc / times.ttf`。
- 配色只用版面色板：主色 #B52525、辅色 #071F65、第三色 #5B6B7A、浅灰 #D0D0D0；网格 #E4E4E4 且 `set_axisbelow(True)`。
- 去顶右框线，轴线 #B7B7B7，刻度朝外 2.2pt。

## 3. 图面只留主体

页面上**不画**图标题、"数据来源"行、说明性小字、口径注释——这些属于图注/口头/备注。
可保留：坐标轴 + 刻度 + 数据标签 + 图例 + 必要的目标值参考线。

- 数据标签：占比 ≥10% 才写在色块内部，小的用 `annotate` 标到条外（白字压在窄色块上会"消失"）。
- 长标签手动换行（matplotlib 不自动折行）。
- 端值标签被裁 → 放宽 `xlim` 后用 `spines['bottom'].set_bounds()` 裁掉空尾巴。
- 堆叠条宽度统一、同色系同语义；不要给"其他"用显眼色。

## 4. 图注写法

`图N　短名`（≤14 字，16pt #8C8C8C）。**不写数据来源、不写年份括号、不写口径。**
来源与口径写进：表注（如果是表）、演讲备注、或交付说明里的「数据口径表」。

## 5. 交付时同时给用户的四件事

1. 图文件（png，命名 `图N_短名.png`）；
2. 取数口径一行：指标定义 + 年份 + 规模/范围 + 出处；
3. 已知的不确定性（如"2025 年分项未公开，仅用总量"）；
4. 若某年缺数，明确说"没找到 2025 分项数据，所以图停在 2024"，不要沉默。

> 用户会追问"没有 25 年数据？"。主动交代缺失年份，比让他发现更好。

## 6. 表格（不是图，但同一套纪律）

- 列 = 评委必核的信息；凡图里已经表达的列，删掉（本次"占比"列与环形图重复，被用户删了）。
- 反例也要记住：多人同校/同单位时，**要加"单位"列**，因为评委要知道归属。
- 合计行加浅底 #F6F5F1 加粗；分年与科目若有 0.01–0.02 的进位差，表注写"以总计为准"。
