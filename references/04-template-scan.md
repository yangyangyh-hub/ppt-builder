# 04 模板解析（S4 阶段）

## 1. 什么时候需要解析

- 用户给了模板 / 参考 PPT / 上次的成品 → 必须解析，**不要凭印象套规格**。
- 用户没给 → 直接用本技能 `assets/template.pptx`（2026-11-23 定稿版），规格见 `01-visual-spec.md`。

## 2. 一条命令拿全景

```bash
python scripts/analyze_pptx.py 模板.pptx -o scan.json
```

输出四块，正好是本阶段要填的四张表：

| 块 | 回答什么 |
| --- | --- |
| `canvas` | 画幅多少（16:9 常见 33.87×19.05 或 25.4×14.29） |
| `skeleton` | 哪些形状每页都在、在什么位置（章节块/标题/副标/logo/页脚线/页码） |
| `type_scale` | 字号有哪几档、各占多少字符（用来定"四档"） |
| `palette` | 实际用到的颜色与用量 |

`skeleton` 的"判据"列有讲究：`版位` = 同位置同尺寸（标题框、页码框、logo），`文本` = 同尺寸同文本模式（章节数字、目录编号）。两者都看才不会漏。

## 3. 要产出的「继承 / 偏离」表（交用户看，最多 3 处偏离）

```markdown
| 项 | 模板原状 | 本套做法 | 原因 |
| --- | --- | --- | --- |
| 正文字号 | 28pt | 20–24pt | 结构化信息量大，28pt 装不下 |
| 表格 | 0 个 | 4 个，统一样式 | 评审要求指标/经费可核 |
| 页数密度 | 41 页 | 14 页 | 答辩时长 15 分钟 |
```

骨架构件（章节块、标题框、logo、页脚线、页码）**一律不动**；只允许改字号档位与内容区网格，且必须写进偏离表。

## 4. 三个必踩的坑

1. **母版深色底不是背景填充，是母版里的形状。**
   只设 `slide.background.fill` 盖不住，必须铺一张 0,0→整页 的白矩形并压到 spTree 第 3 个节点（`spTree.insert(2, el)`）。否则每页都带模板的深蓝 V 形和"视界PPT"水印。
2. **新建页必须选占位符最少的版式**，别用 `slide_layouts[0]`（通常是带装饰的封面版式）；建好后把残留 placeholder 全部删掉。
3. **每个 run 都要写 `lang="zh-CN"`**（`rPr.set('lang','zh-CN')`），否则中文按西文断行，标点会跑到下一行行首。`hangingPunct` 单独加无效。

## 5. 从模板抄什么、不抄什么

| 抄 | 不抄 |
| --- | --- |
| 画幅、章节块、标题/副标位置、logo、页脚、色板 | 模板的页数节奏、章节过渡页、动画、母版装饰图形 |
| 字号四档的"层级关系" | 绝对字号（按本套内容重新定，下限仍为 16） |
| 表格的配色逻辑 | 具体列数与列宽 |

> 仓库里刻意不带 logo（单位标识不宜公开）。把你的横版校名图存成 `assets/school-logo.gif`（png 也可以，改 `build_deck.py` 里的 `DEFAULT_LOGO` 后缀），或在页面 spec 里写 `"logo": false` 让它完全不画。

## 6. 若模板只有图片（截图/PDF）

按像素量：`np.array(PIL).sum(axis=2) < 720` 找非白段 → 换算 cm。用 `px / 页面像素宽 × 33.87` 得 cm 值。**不要靠肉眼估**，缩放会让人误判"等大"。
