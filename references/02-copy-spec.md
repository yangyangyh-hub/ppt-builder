# 02 文案与表述规则

> 这批规则来自用户对初稿的逐句改写：**删掉一半修饰，保留全部数字**。写页面文案前先读这一份。

## 1. 三层文案（写稿必须分层，不要混）

| 层 | 上不上页面 | 篇幅 |
| --- | --- | --- |
| L1 说明 | 不上，只在对话里交代"这页放什么、怎么排" | 不限 |
| L2 页面文案 | 上页面 | 每句 ≤ 40 字；每页 180–280 字（表页除外） |
| L3 演讲备注 | 上备注栏 | 80–110 字 = 本页讲什么 + 1 个可能被追问的应答点 |

备注必须与页面内容对版：**删页、并页之后要重新对一遍备注**（原稿删掉一页后，备注整体错位一页，没人发现）。

## 2. 六类必做改写

| 类型 | 反例（初稿） | 正例（定稿） |
| --- | --- | --- |
| 去机理修饰 | 非常规饲料原料**营养价值**数据不足，**抗营养因子与毒素影响其稳定利用** | 非常规饲料原料数据不足，高效利用不足 |
| 删"标签：值" | `人才称号：…` `科研奖励：…` `团队负责人：…` | 直接陈述，靠红竖条/加粗/缩进分层 |
| 虚词换硬数 | "发表论文若干、获多项专利" | "论文 40 余篇、专利 19 项、项目 40 余项" |
| 单元格短语化 | "样品处理至结果判读不超过 2 小时" | "小于 2 小时" |
| 合并同类条 | 四条（平台/人员/领域/协作）各占一行 | 三条，平台类并到另一页去说 |
| 一句一动作 | "系统评价并明确形成……方案" | "形成分阶段低蛋白日粮配制方案" |

## 3. 逐条写法约定

- 中文为主；专业术语首次出现用 `中文（English）`。
- 数字与单位间半角空格：`2 万头`、`440.42 万元`、`2.55∶1`（比号用 ∶ 不用 :）。
- 年份区间用全角破折号：`2020—2025 年`；不要 `2020-2025年`（半角连字符是原文遗留，出现即视为待统一）。
- 括号只放"补充限定"，不放来源；来源放表注或口头。
- 一页一个判断句，不要在一页里同时讲背景、方法、结果。

## 4. 禁用

- 营销词：打造、赋能、引领、致力于、显著提升、全新、颠覆。
- 评价句：「不是……而是……」「具有重要意义」。
- 过程痕迹上页面：待插入、待补、示意图、占位、TODO、XX、待本人确认（这些只能出现在交付说明里，不能进 PPT）。
- 自创标题：「关于……的思考」「浅析……」；页标题只写名词短语。
- 一页两个并列中心（两个 24pt 结论句）。

## 5. 事实纪律

- 人名、职称、单位、项目名、经费数字：材料里没有就**不写**，统一在交付说明里列「待本人确认」，不在页面上留空或猜。
- 单位名写全称（如"示例大学动物科学学院"），不缩写。
- 涉及"谁属于哪个单位"这类归属，以用户给的材料为准；用户改动过的地方不要按常识改回去。踩过的坑：把某个合作团队的单位按"常识"纠正，结果纠成了错的。
- 数字口径冲突时，同一页不并列两个口径；要么选一个并在表注说明，要么分两张图。
