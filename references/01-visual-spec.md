# 01 版式规格（实测值，不是估算）

> 来源：2026-11-23 定稿的 14 页汇报 PPT 逐形状量测。**所有数字单位 cm，画幅 33.87 × 19.05（16:9）。**
> 改规格 = 改这一份 + `scripts/build_deck.py` 顶部常量，两处必须同改。

## 2. 内容区与网格

- 内容左边界 **1.70**，右边界 **32.10**，可用宽 **30.40**；内容上边界 3.50（副标下方），下边界 18.60。
- 左对齐一律对齐 1.70，**不要在 1.45/2.05/2.25 之间来回换**（原稿三种混用，视觉会漂）。
- 三列：宽 9.55，起点 1.70 / 12.02 / 22.34（步长 10.32，间距 0.77）。
- 两列：宽 14.00–14.20，起点 2.05 / 17.25（或 2.25 / 17.40），列间距 ≈ 2.0。
- 六段链条：宽 4.90，间距 0.30（原来用 5.05 紧贴，字距挤）。
- 底部通栏：l=1.70 w=30.40 h=0.85，y=17.45，20pt 白字；页面若有通栏，其上方所有元素底部不越过 17.35。

## 3. 字号四档（下限 16，硬规则）

| 用途 | 字号 |
| --- | --- |
| 封面主标题 | 44（单行，不断行） |
| 目录标题 / 结束页主文 | 54 / 40 |
| 页标题 | 34 |
| 副标、卡片小标题、中心句、正文（宽松页） | 24 |
| 正文（信息密页）、通栏、流程块、表格 | 20 |
| 表格（≥6 行或 5 列以上） | 18 / 15 |
| 图注、页码、表注、说明、图表刻度 | 16 |

- **全篇禁止 < 16pt**。放不下就删字、删列、删页，**不降字号**（这是本条最重要的判断顺序）。
- 单页主讲文字 180–280 字为常态（不是 60 字）；超过 300 字说明这页该拆。
- 段落：多段正文 行距 1.5、段前 5pt；单段标题类 行距 1.0；卡片正文 1.15–1.2。
- 对齐：**左对齐**。两端对齐会让含数字的中文行出现大空隙（"降低　6%"），只在纯中文短句用 JUSTIFY。

## 4. 配色（只用这 7 个）

| 用途 | 色值 |
| --- | --- |
| 正文 | #060607 |
| 结构色（章节块、表头、通栏、竖条、副标） | #B52525 |
| 关键数字砸色 | #FF0000（一页≤2 处） |
| 图注 / 次要说明 | #8C8C8C |
| 页码 | #9A9A9A |
| 浅底块（流程 chip、卡片） | #F2F0EB |
| 合计行 / 更浅底 | #F6F5F1 |
| 表格横线 | #D8D8D8 |

字体：中文 **微软雅黑**，西文 **Times New Roman**，全部加粗（表体除外）。每个 run 必须写 `lang="zh-CN"`，否则中文断行把标点甩到下一行行首。

## 5. 表格样式

- 表头：#B52525 底、白字、加粗、与表体同号或 +2pt。
- 表体：无填充（合计行 #F6F5F1）、#060607、**不加粗**（与全篇加粗形成层级差）。
- 框线：**只有横线**，表头下 1.0pt #B52525，其余行底 0.75pt #D8D8D8；无竖线、无斑马纹。
- 行高 ≥ 字号 × 0.0353 × 1.30（20pt → 0.92cm）。低于这个值 PowerPoint 会自己撑高，把下方元素顶掉。
- 列宽按"评委要核的信息"分配，首列左对齐，数字列居中右对齐；表格整体居中于页面中心（16.95）。
- 表下注 16pt 灰字，写来源、"以总计为准"这类口径说明；**不要写"待补"**。

## 6. 图片

- 一律等比裁切填满目标框（`crop_*`），**不拉伸**；人物竖幅 2:3，场景横幅 16:10，证书类可错位叠放。
- 一页 1–2 张大图优于四联小图；四联只在确实有四类不同实物时用。
- 图注：`图N　短名`，≤14 字，16pt #8C8C8C，贴图左下，**不写来源、不写年份括号、不写口径**（来源留给口头与备注）。
- 图号只数页面上真实存在的图，无图不占号。

## 7. 页面原型（5 种覆盖 90% 场景）

| 原型 | 结构 | 用于 |
| --- | --- | --- |
| 封面 | 标题 44 单行 + 红线 + 副题 + 三行落款 | 首页 |
| 目录 | 左"目录/CONTENT"，右 6 条红圈编号 | 目录（≤6 条） |
| 三列 + 三图 | 三条判断（24pt）+ 三图横排 + 通栏 | 问题/现状/三张证据 |
| 流程 + 2×2 | 中心句 + 六段链条 + 四块产出 + 通栏 | 目标/成效/体系 |
| 表页 | 表 + 下方双栏文案 或 表 + 右侧图 | 指标/经费/名单 |
| 卡片页 | 2×2 卡片（红竖条）+ 底部 1–2 图 | 条件/平台/保障 |
| 满幅图 | 一张大图 + 图注 | 技术路线/架构图 |
| 结束页 | 40pt 一句话 + 联系方式 | 末页 |
